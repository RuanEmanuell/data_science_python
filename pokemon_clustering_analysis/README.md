## Pokémon Clustering Analysis

### What is this? 🤔
This project applies machine learning clustering algorithms using Python to a Pokémon dataset available on Kaggle.

The goal of this project is to group Pokémon with similar characteristics into clusters based on multiple attributes such as attack, defense, speed, height, weight, generation, type, and other statistical characteristics.
