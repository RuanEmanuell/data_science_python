## Análise de Agrupamento de Pokémon

### O que é isso? 🤔
Este projeto aplica algoritmos de agrupamento (clustering) de machine learning utilizando Python em um dataset de Pokémon disponível no Kaggle.

O objetivo deste projeto é agrupar Pokémon com características semelhantes em diferentes clusters, com base em múltiplos atributos como ataque, defesa, velocidade, altura, peso, geração, tipo e outras características estatísticas.
