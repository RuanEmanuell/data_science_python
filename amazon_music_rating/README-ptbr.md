## Sistema de Recomendação de Músicas (Amazon Music)

### O que é isso? 🤔
Este projeto aplica um algoritmo de filtragem colaborativa utilizando Python em um dataset de avaliações de músicas da Amazon.

O objetivo deste projeto é prever notas e recomendar itens musicais para usuários com base no comportamento de usuários semelhantes.
